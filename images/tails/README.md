# Tail / registration close-ups

Real aircraft photos cropped to the empennage / engine registration area for **Tail / country** mode.

- `manifest.json` maps each file → country id + visible registration
- Prefer player `images/user/` crops when the mark is readable; otherwise Commons exteriors
- Quiz uses the painted registration when present; country options stay 4-wide with teach-first reveal

## Accuracy

- MX asset is Challenger 650 **XA-OOI** (cn 6122; Commons ZLEA @ DAB). Earlier label XA-ODI was a misread of OOI.
- MX country distractors prefer X- / prefix-confusable marks (IL 4X-, UY CX-, BR PP/PR/PT-) rather than geography neighbors.
